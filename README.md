# Stockhold

Multi-tenant inventory reservation API that prevents overselling under flash-sale traffic.

> Status: under construction. Full documentation arrives in Phase 16.

## Planned stack

- API: Java 21, Spring Boot 3, PostgreSQL 16, Flyway
- SDK: TypeScript, Vitest
- Dashboard: React, Vite, Tailwind, TanStack Query
- Tests: JUnit 5, Testcontainers, k6
